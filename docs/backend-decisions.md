# 後端設計與交接 v0.1

日期：2026-10-14

## SA → SD

已確認：目擊與餵養並存；公開暱稱與照顧紀錄；訪客概略位置，登入詳細位置。

暫定：未辨識紀錄不強制建立動物；0.01 度格網中心；公開紀錄隱藏備註與照片連結。這些選擇可修改，需產品負責人確認。

## SD → PG

Java 21 + Spring Boot 4.1.1。採單一 REST 應用，JDBC 參數化 SQL，Flyway 管理資料結構。MySQL 為目標資料庫，H2 為本機／整合測試資料庫。

資料關係：會員一對多紀錄；動物一對多紀錄；紀錄可不關聯動物；會員一對多有效期 token。會員 email 與密碼雜湊不出現在公開 DTO。

登入採撤銷式不透明 Bearer token，資料庫只存 token 雜湊；不使用 cookie session。CSRF 關閉限於此認證模式，未來改用 cookie 必須重新設計。

## PG → QA

驗收重點：所有公開紀錄路徑均不得回傳原座標；登入才能寫入；無效或登出 token 不能讀詳細資料；事件類型、時間、座標、動物存在性與分頁必須驗證。

## 未完成項目

真正 MySQL 驗證、照片上傳、紀錄修改／刪除、動物合併、地圖空間查詢、活動區域推估及正式部署均未完成。沒有舊資料可進行遷移。
