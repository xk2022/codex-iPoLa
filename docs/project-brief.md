# 流浪貓狗系統：需求摘要 v0.1

更新日期：2026-10-14

## 目標

讓台灣各地關心流浪貓狗的人記錄目擊與餵養事件，累積動物出現位置與時間，協助了解可能活動範圍，以及參與照顧的人。

## 使用者已確認

- 紀錄接受目擊與餵養，分開標示。
- 第一版顯示照顧者暱稱與照顧紀錄。
- 公開概略位置，登入後可查看詳細位置。
- 可以完全重構；使用者描述原課程專案採 Spring MVC、MySQL 與 SQL。

## 建議，尚未確認

- 新增紀錄時可關聯既有動物、新增動物，或保留為尚未辨識。
- 第一版以人工比對照片與特徵認定動物。
- 地圖先呈現歷史出現點；推估活動區域的方式另行設計。

## 待釐清

- 同一隻動物的認定、錯誤關聯與合併規則。
- 公開概略位置的精度與處理方式。
- 紀錄必填欄位、修改與刪除權限。
- 舊資料是否存在，以及是否需要遷移。

## 合作方式

使用者負責業務規則、優先順序與驗收；AI 先承擔 PM／BA／SA，依需求進展再進入設計、開發與品質驗證。需求決策必須區分已確認事項與提案。
